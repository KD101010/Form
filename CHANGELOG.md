# Form v3.0 Changelog

## Experience
- Added one-time onboarding.
- Added local-time greeting and first-name personalization.
- Replaced repeated daily setup questions with saved defaults.
- Added the next planned workout directly to Home.
- Added optional per-workout adjustments.

## Training plan
- Added sequence-based splits.
- Added Form-recommended plans and user-selected plans.
- Planned workouts advance only after completion.
- Profile changes affect future workouts without rewriting history.

## Workout generation
- Added experience, recent-history, priority, dislike, limitation, and behavior inputs.
- Added structured exercise family, pattern, role, difficulty, and video-ready metadata.
- Added recent-exercise rotation.
- Added higher-value movement preservation for shortened workouts.

## Swaps and preferences
- Swaps now require a different movement family when possible.
- Swaps and skips are recorded.
- Repeated rejection behavior reduces future prescription frequency.

## Tracking and progression
- Previous exercise performance is shown.
- Prior weight is prefilled.
- A conservative load increase can be suggested after the top of the rep range is completed.
- Body-weight entries are stored as history.

## History and feedback
- Completed workouts are tappable.
- Drill-down includes exercises, sets, reps, weights, swaps, and skips.
- Post-workout difficulty feedback remains optional.
- Added share-sheet beta feedback.

## Reliability
- Preserved interrupted-workout resume.
- Updated cache version and asset URLs.
- Preserved the approved iPhone Home Screen icon.
- Added automatic v2 history migration.
