# Form Workout App

## Easiest way to preview it

1. Extract the ZIP folder.
2. Open the extracted folder.
3. Double-click **Form-Preview.html**.

That single file contains the entire preview. You do not need GitHub, an app, a web server, Python, or the command line.

## Putting it on an iPhone later

The other files are the hosted version. Once the design is approved, upload those files to GitHub Pages or another web host, open the resulting address in Safari, and choose **Share > Add to Home Screen**.

## Included

- Guided workout builder
- Goal-based sets and reps
- Home gym, full gym, and bodyweight choices
- Energy and limitation adjustments
- Exercise substitutions
- Active workout tracking
- Workout timer
- Local workout history

## Important

This prototype stores history on the device when browser storage is available. It does not provide medical advice. Stop exercising if an activity causes pain and consult a qualified professional regarding injuries or medical conditions.
