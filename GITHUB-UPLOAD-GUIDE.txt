FORM V3.2 GITHUB UPLOAD GUIDE

This release uses the SAME GitHub repository and the existing GitHub Pages configuration.

If uploading manually:

1. Extract the Form v3.2 GitHub-ready ZIP.
2. Open the existing Form GitHub repository.
3. Click Add file -> Upload files.
4. Upload EVERY individual file from inside the extracted build folder.
5. Do not upload the ZIP itself and do not create a nested build folder.
6. Confirm index.html remains at the repository root.
7. Suggested commit message:
   Release Form Beta v3.2 - Today's Setup + Reliability
8. Commit to main.
9. Wait for GitHub Pages to redeploy.

VERIFY V3.2

1. Open the live Form website and refresh.
2. Open the three-dot menu -> Equipment. Confirm Setup details are present.
3. Return Home -> Adjust workout. Confirm Anything different today? appears.
4. Choose Dumbbells only + No bench and build a workout.
5. Confirm no bench-supported exercise appears.
6. Open the three-dot menu -> Data & Backup and confirm Export backup / Import backup are present.
7. Start a workout, complete a set, use Swap, and confirm completed work remains represented in History after finishing.
8. Confirm the rest strip does not start after the final remaining set.

IF THE OLD VERSION APPEARS

1. Open the live website directly in Safari and refresh.
2. Fully close Form from the app switcher and reopen it.
3. If Form shows an Update ready prompt, choose Update Form.
4. If the installed Home Screen app still appears stale, delete the Form Home Screen icon.
5. Open the live website again in Safari and refresh.
6. Tap the three dots at the bottom-right -> Share -> View More -> Add to Home Screen.
7. Confirm the name says Form and add it again.

DATA NOTE

v3.2 preserves the existing v3 local-storage keys. Deploying new GitHub Pages files should not erase an existing user's profile or history. Browser-data deletion, private browsing, storage pressure, or device loss can still remove local data, which is why v3.2 adds user-initiated backup export.
